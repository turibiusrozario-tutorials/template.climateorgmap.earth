Set up your map

A checklist that checks itself: each step turns green once it's done. Keep this page open while you set up. It is public but harmless (it shows nothing private).

  1. Your map's website done

    You're looking at it. This is its address. The sheet asks for it in step 3.

  2. Name, state and land acknowledgement checking…

    All three are in one file, map.config.ts. Edit it on GitHub (pencil icon → change → Commit changes). The site rebuilds in about a minute; reload this page.

    Edit map.config.ts on GitHub

  3. Google Sheet and forms checking…

    1. Open sheets.new (a blank Google Sheet). Name it, e.g. "your map data".
    2. Extensions → Apps Script. Select everything in Code.gs and delete it, then paste the sheet script:
    3. Click Save (💾). Go back to the sheet tab and reload it. A menu named after your map appears (give it a few seconds).
    4. That menu → Set up sheet + forms (run once). Allow the permissions (if Google says the app isn't verified: Advanced → Go to … (unsafe); it's your own script). Paste the address from step 1 when asked, and your core team's emails.

  4. Publish the sheet's data checking…

    1. In Apps Script: Deploy → New deployment → ⚙ Web app. Execute as: Me. Who has access: Anyone. Deploy, allow, then copy the Web app URL (ends in /exec).
    2. Paste it into map.config.ts as dataUrl: edit map.config.ts. Commit, wait a minute, reload this page.

  5. Forms connected to the map checking…

    Nothing to copy: the map reads the forms from the sheet. Try it: open the map, press +, and add a test organization. As an admin, it appears after a reload (about a minute). Delete test rows in the sheet when you're done.

  6. Sheet script up to date checking…

    After you get updates (GitHub: your repo → Sync fork → Update branch), the site may have a newer sheet script. To update the sheet: copy the script (step 3), paste it over Code.gs, Save, then Deploy → Manage deployments → ✏️ → Version: New version → Deploy (the URL stays the same), and run the menu's Update the forms.

More: open the map · custom address (like wi.climateorgmap.earth), handover and updates are in the repo's README.

This page reads region.json and version.json from this site and, once it's set, the sheet's public web app.
